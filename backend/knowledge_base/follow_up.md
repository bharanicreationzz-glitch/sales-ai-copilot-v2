# Follow-Up Guidance

knowledge_type: follow_up

## Rule

Every follow-up should have a purpose.

Avoid:
- "Sir any update?"
- "Sir decided?"
- "Sir please call."
- Repeated generic messages.

Prefer:
- Reference the previous conversation.
- Add value.
- Address the unresolved barrier.
- Ask for one next step.

## After price discussion

"Hi sir, just following up on the fencing requirement we discussed. Have you finalized the boundary length and height? Once those are confirmed, we can proceed with the appropriate quotation."

## After product comparison

"Hi sir, last time we discussed the two fencing options. Have you decided which factor is more important for your site — strength, maintenance or budget?"

## After decision delay

If customer said:
"I'll decide next month."

Do not call every few days.

Follow up closer to the agreed timeline:
"Hi sir, when we spoke earlier you mentioned you were planning to start the fencing around this month. I wanted to check if the project is now ready and whether you need the quotation updated."

## Follow-up objective

Every follow-up should move one of these forward:
- Requirement
- Product decision
- Price clarification
- Site information
- Installation
- Decision-maker
- Timeline
- Quotation
- Site visit
- Order

## Next-step rule

Try to establish:
WHAT + WHEN + NEXT ACTION
